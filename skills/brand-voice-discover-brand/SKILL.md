# Discover Brand Materials

Search connected platforms for brand-relevant content:

1. **Identify connected sources**, list active MCP connectors
2. **Search broadly**, brand guidelines, style guides, voice docs, logo files, customer interviews, sales decks
3. **Triage results**, rank by relevance + freshness
4. **Produce discovery report** with:
 - Source list with confidence scores
 - Categorized findings (Voice / Visual / Strategy / Sales)
 - Recommended next steps (generate guidelines? consolidate? archive?)

Delegate heavy search/triage to discover-brand agent.
