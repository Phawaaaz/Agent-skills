# Web page design

Patterns from web-design reels the user saved. The recurring message: most sites use the same template (headline and button left, image right) and nobody remembers them. Pick a deliberate structure for each section instead.

## Hero sections: don't default to "text left, image right"
Choose one of these on purpose:
| Style | What it is | Good for |
| --- | --- | --- |
| Wordmark | The brand name fills the screen; the product sits on top of it | Brands that want the name remembered |
| Split | The headline breaks around the product | Fintech, SaaS, single-product brands |
| Full-bleed | Giant type over one edge-to-edge photo | Hardware, physical products |
| Orbit | Headline in the middle, photos floating around it | Agencies, studios, portfolios |
| Editorial | Big statement block plus oversized single word across the page | Studios, opinionated brands |
| Magazine | Huge display type as the visual, short line of copy beneath | Lifestyle, consumer brands |

## About pages: five sections that build trust
Don't stop at contact details. Combine some of:
1. **Founder letter**: a real human voice behind the brand.
2. **Timeline of origin**: where it started and where it is now, with real dates and milestones.
3. **Team culture**: real names, faces and roles.
4. **Manifesto**: a bold statement of what the brand believes.
5. **Numbers**: proof such as clients served, years, products sold.

## Too much text? Distribute it, don't just cut it
1. **Heading hierarchy**: break one block into a main heading, subheadings and short text.
2. **Two columns**: magazine style; shorter lines are easier to read.
3. **Three columns**: split a big block into three side-by-side parts.
4. **Side labels**: short paragraphs on the right, small titles on the left.
Guide the reader from most important to least important.

## Spacing values (premium feel)
| Gap | Desktop | Mobile |
| --- | --- | --- |
| Heading → subheading | 8–16 px (big hero headline: 24–40 px) | same scale, slightly tighter |
| Text ↔ image | 24–40 px | 16–24 px |
| Between main sections | 80–120 px | 48–64 px |
| Text → its CTA button | 16–24 px | 12–16 px |
The bigger the heading, the more space it needs. Keep the button close to its message so it reads as that message's action.

## Mobile rules
1. **Thumb-sized buttons**: enough height and padding to hit with a thumb.
2. **Vertical scrolling**: design everything to flow straight down.
3. **Show less**: hide extra columns and side content on the first screen.
4. **Flexible media**: use images that aren't cropped too tight so they still fit on any screen.
5. **Breathing room**: generous padding, margins and gaps between sections.

Editorial layout on mobile: main heading fills the top third; a 2-column grid with a small label on the left and a paragraph on the right; secondary text in the corners; single-word page titles large enough to identify each page; a full-screen menu with vertically stacked items and a large logo at the bottom.

## Footers
Try more than one variation before settling: minimal (logo, a line, legal), content-heavy (newsletter sign-up plus link columns), or a full-bleed visual footer with a big closing headline and one CTA.

## Header copy: headings to ban
| Instead of | Do this |
| --- | --- |
| "Welcome to [Brand]" | Say something useful immediately; they already know your name |
| "About us" / "About me" | Make the heading itself say something about you |
| "What makes us different" | Let the whole site show the difference |
| "Our story" / "My story" | Just start telling it ("It all started when…") |
| "Ready for [vague result]?" | Name the specific outcome |

## Review checklist
- [ ] Is the hero a deliberate style from the table, not the default split?
- [ ] Does each long text area use hierarchy or columns?
- [ ] Do section gaps match the spacing table on desktop and mobile?
- [ ] On mobile: thumb-sized buttons, single column, less on the first screen?
- [ ] Are any banned headers left?
