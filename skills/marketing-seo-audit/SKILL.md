# SEO Audit

## Coverage

1. **Keyword research**, primary + LSI + intent
2. **On-page**, titles, meta, headers, internal links, image alts
3. **Technical**, sitemap, robots, schema, core web vitals
4. **Content gaps**, what competitors cover that we don't
5. **Backlink quality**, top referrers + lost links

## Output

Prioritized action list:
- **Quick wins** (≤1 day, ≥5% expected impact)
- **Strategic investments** (longer, higher impact)
- **Cleanup** (low impact, low effort)
