# Brand Review

## Checks

1. **Tone match** vs voice guidelines
2. **Vocabulary**, approved + forbidden
3. **Sentence rules**, length, voice, address
4. **Claims**, substantiated? legal-risky?
5. **Disclaimers**, required ones present?

## Output

Table: Issue / Severity (🔴🟡🟢) / Original / Suggested fix / Reason
