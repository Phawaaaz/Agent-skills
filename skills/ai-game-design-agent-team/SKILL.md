# AI game design agent team

Develop a cohesive game concept using the user's provided genre, audience, setting, art direction, platforms, mechanics, budget, and schedule. Ask about missing constraints only when they materially affect the result; otherwise state reasonable assumptions.

Consider narrative and world-building, gameplay systems and progression, visual and audio direction, and technical architecture and production planning. Integrate these perspectives into a consistent design, resolve conflicts, and scale the detail to the request. Include implementation priorities, major risks, and budget or timeline estimates only when useful, making uncertainty explicit.

The original application description is in [references/source.md](references/source.md). Its AG2 setup is background, not a requirement to install software, use API keys, or run an external app. Use subagents only when explicitly authorized or required by higher-priority instructions; otherwise apply the specialist perspectives directly.
